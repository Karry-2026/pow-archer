# 爆裂弓箭手

一个跑在浏览器里的 3D 俯视角割草游戏。美漫风格，单文件，零外部素材。

参加 WorkBuddy「1024 造物挑战」程序员节应用创作大赛的作品。

**在线试玩**：https://karry-2026.github.io/pow-archer-play/

## 怎么跑

直接双击 `index.html`，或者起一个静态服务器：

```bash
python -m http.server 8899
# 浏览器打开 http://127.0.0.1:8899/index.html
```

需要联网，因为 Three.js 走 CDN。

## 玩法

| 操作 | 键盘 | 触屏 |
|---|---|---|
| 移动 | WASD / 方向键 | 拖拽左半屏 |
| 攻击 | 自动，无需操作 | 自动 |
| 背包 | TAB | 点背包按钮 |
| 暂停 | ESC | 点暂停按钮 |
| 静音 | M | 点左上角喇叭 |

一局 10 波，每波约 34 秒。第 5 波和第 10 波出 BOSS，BOSS 出场前会清场并暂停波次计时。

- 击杀掉经验球，球会自动飞向你（半径 4.6），捡够升级
- 升级三选一：武器升级 / 新武器 / 被动，满级武器可无限叠「极限突破」
- 宝箱**只升级已有武器和被动**，不会硬塞新武器
- 武器满级 + 对应被动 3 级 = 超武进化，整局只能选一个
- 第 5 波「裂口巨兽」贴地冲锋，第 10 波「千手墨神」悬浮弹幕

主页有图鉴，敌人 / 武器 / 被动三页随时可查。

## 技术要点

- **渲染**：Three.js r150，透视相机，固定俯视角度，相机硬跟随不做插值
- **卡通着色**：`MeshToonMaterial` + 手写色阶贴图
- **描边**：背面外壳沿法线外扩 0.03（不是整体缩放，缩放会把小部件整个包黑）
- **性能**：敌人、子弹、宝石、粒子全部走 `InstancedMesh` 池
- **建模**：多部件几何合并成单一带顶点色的几何，一个小怪只有 2 个 draw call
- **音频**：Web Audio 实时合成，三首段落式曲子 + 全部音效，零音频文件
- **顿帧**：只冻结世界，玩家移动和开火始终使用真实时间
- **数值**：TTK 对齐法，BOSS 血量由「预估 DPS × 目标秒数」派生

## 开发约定

1. **每一笔改动都要在 `docs/DEVLOG.md` 留记录**，写清根因、做法、验证方式。
2. **数值改动先改表，再改代码**，改完跑 `docs/tools/calc_curve.py` 校验 DPS 曲线自洽。
3. **内容获取途径保持唯一**。宝箱只升级已有内容，新武器只能从升级三选一里来。
4. **同一个数字不允许在两处各写一遍**。图鉴、背包、结算显示的数值都从配置读。
