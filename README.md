# 爆裂弓箭手（POW! ARCHER）

一个跑在浏览器里的美漫风格 3D 俯视角割草游戏：单文件、零图片、零音频文件、零后端（WebAudio 实时合成三首段落式配乐与全部音效）。

参加 WorkBuddy「1024 造物挑战」作品。**全程 AI 协作、零手写代码交付**，重点验证非程序员如何用 **需求文档（PRD）+ 三方数值对账脚本 + 回归断言 + 版本日志（DEVLOG）** 管住 AI 产出、拦截静默错误。

**在线试玩**：https://karry-2026.github.io/pow-archer/

## AI 协作工程验收要点（为什么看这个仓库）

1. **三方对账防手抄错误**：运行 `python docs/tools/audit_numbers.py` 与 `python docs/tools/calc_curve.py`，自动核对 `index.html` 常量、Excel 配置表与手册文档，防止数值漂移。
2. **用自动化断言拦住 AI 静默错误**：实测拦截并修复过「攻速加成只写 UI 未接入开火间隔」「BOSS 穿透弹每帧重复结算」「超武卡必出」「开局音频淡入导致前 1 秒静音」「桌面端右上角 KILLS 被音量按钮遮挡」等隐蔽缺陷，全程记录在 `docs/DEVLOG.md`。
3. **版本留痕与随时回退**：21 个版本标签串联 7 天立项到 v0.20 精细度升级，每笔改动均有根因、做法与验证证据。

## 怎么跑

直接双击 `index.html`，或者起一个静态服务器：

```bash
python -m http.server 8899
# 浏览器打开 http://127.0.0.1:8899/index.html
```

需要联网，因为 Three.js 走 CDN。

## 玩法

开局先选职业，武器与超武由职业与流派构筑决定（v0.18 收敛为 4 职业 / 2 流派）：

| 职业 | 起手武器 | 流派 | 定位 | 超武进化 | 必杀 |
|---|---|---|---|---|---|
| 散射 | 爆裂弓 | 远程 | 扇形铺开覆盖 | 箭雨 | 暴雨模式 |
| 激光手 | 穿透激光 | 远程 | 单线重击贯穿 | 湮灭射线 | 过载贯穿 |
| 连刃 | 连刃 | 近身 | 绕身呼吸两段绞杀 | 刃轮 | 血月 |
| 炸弹手 | 抛掷炸弹 | 远程 | 范围爆破清场 | 陨石雨 | 空袭 |

| 操作 | 键盘 | 触屏 |
|---|---|---|
| 进入 | 点「点击进入」（先加载，音乐随即起播） | 同左 |
| 移动 | WASD / 方向键 | 按住屏幕任意位置滑动 |
| 攻击 | 自动，无需操作 | 自动 |
| **超武必杀** | **空格**（蓄力环满了才有效） | 点右下角蓄力环 |
| 背包 | TAB | 点背包按钮 |
| 暂停 | ESC | 点暂停按钮 |
| 静音 | M | 点右上角喇叭 |

一局 10 波，每波约 34 秒。第 5 波和第 10 波出 BOSS，BOSS 出场前会清场并暂停波次计时。

- 击杀掉经验球，球会自动飞向你（半径 4.6），捡够升级
- 升级三选一：武器升级 / 新武器 / 流派精通，满级武器可无限叠「极限突破」
- **两条流派**：近身（连刃）、远程（爆裂弓 / 穿透激光 / 抛掷炸弹），外加全武器通用的「急速」攻速被动。
  流派精通只加成自己那条线，混着点会摊薄 —— 这是构筑有辨识度的根本
- 同一条线带满 2 把武器 = 套装，该流派伤害再 ×1.30
- 宝箱**只升级已有武器和被动**，不会硬塞新武器
- 武器满级 + 同流派精通 2 级 = 解锁超武进化卡（进池竞争 + 三级保底），整局只能选一个
- 超武进化后右下角有**蓄力环**，转满按空格放必杀（暴雨模式 / 过载贯穿 / 血月 / 空袭）
- 第 5 波「裂口巨兽」贴地冲锋，第 10 波「千手墨神」悬浮弹幕
- BOSS 目标时长 32 / 45 秒，62% 转阶段（无敌 + 召唤 + 护盾）、30% 狂暴

主页有图鉴，敌人 / 武器 / 被动三页随时可查。

## 技术要点

- **渲染**：Three.js r150，透视相机，固定俯视角度，相机硬跟随不做插值
- **卡通着色**：`MeshToonMaterial` + 手写色阶贴图
- **描边**：背面外壳沿法线外扩 0.03（不是整体缩放，缩放会把小部件整个包黑）
- **性能**：敌人、子弹、宝石、粒子全部走 `InstancedMesh` 池
- **建模**：多部件几何合并成单一带顶点色的几何，一个小怪只有 2 个 draw call
- **音频**：Web Audio 实时合成，三首段落式曲子 + 全部音效，零音频文件
- **顿帧**：只冻结世界，玩家移动和开火始终使用真实时间
- **数值**：TTK 对齐法，BOSS 血量由「预估 DPS × 目标秒数」派生

## 开发约定

1. **每一笔改动都要在 `docs/DEVLOG.md` 留记录**，写清根因、做法、验证方式。
2. **数值改动先改表，再改代码**，改完跑 `docs/tools/calc_curve.py` 校验 DPS 曲线自洽。
3. **内容获取途径保持唯一**。宝箱只升级已有内容，新武器只能从升级三选一里来。
4. **同一个数字不允许在两处各写一遍**。图鉴、背包、结算显示的数值都从配置读。
5. **改任何数值后跑 `docs/tools/audit_numbers.py`**。它对着代码核配置表和三份文档；退码非 0 就是有人手抄错了。
6. **发版走 `docs/VERSIONS.md` 第六节的十步流程**。顺序不能换 —— 先跑测试再写日志，先改版本表再打标签。
