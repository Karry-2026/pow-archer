# POW! ARCHER · 爆裂弓箭手

一个跑在浏览器里的 3D 俯视角割草游戏。美漫风格，单文件，零外部素材。

参加 WorkBuddy「1024 造物挑战」程序员节应用创作大赛的作品。

## 怎么跑

直接双击 `index.html`，或者起一个静态服务器：

```bash
python -m http.server 8899
# 浏览器打开 http://127.0.0.1:8899/index.html
```

需要联网，因为 Three.js 走 CDN。

## 玩法

| 操作 | 说明 |
|---|---|
| WASD / 方向键 / 触屏左半屏摇杆 | 移动。攻击全自动，角色朝最近的敌人开火 |
| TAB | 打开背包 |
| ESC | 暂停（可在这里调怪物刷新频率） |

一局 10 波，每波 30 秒。第 5 波和第 10 波出 BOSS。

- 击杀掉经验宝石，捡够升级，升级三选一
- 地上随机刷宝箱，走过去自动开，出随机武器和被动
- 武器满级 + 对应被动 3 级 = 超武进化，6 把武器各有一个进化形态
- 全部满级后不再出现垃圾选项，转为无限叠加的「极限突破」

## 技术要点

- **渲染**：Three.js r150，正交透视相机，固定俯视角度
- **卡通着色**：`MeshToonMaterial` + 手写 4 阶色阶贴图
- **描边**：背面外壳外扩（inverted hull），不需要后处理
- **性能**：敌人、子弹、宝石、粒子全部走 `InstancedMesh` 池，同屏 170 个敌人只有个位数 draw call
- **音效**：Web Audio 实时合成，没有音频文件
- **贴图**：地板、光斑全部用 Canvas 2D 现场画，没有图片文件
